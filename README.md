# High School Game Design Projects

This repository contains a collection of projects completed during my Intro to Game Design course. These projects serve as a portfolio of my early work in game design.

## Project Scope and Contributions

The work showcased in this repository focuses on the creative aspects of game design. 

*   **Design and Aesthetics:** I was responsible for the visual direction, level layouts, character positioning, and overall player experience.
*   **Code Attribution:** All underlying source code, logic scripts, and engine configurations were provided by the instructor.
